# 🎙 TechWave Podcast Website

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=for-the-badge\&logo=github)](https://sohanur-rahman-coding.github.io/Tech-Wave/)

GitHub Repo: [https://github.com/sohanur-rahman-coding/Tech-Wave](https://github.com/sohanur-rahman-coding/Tech-Wave)

## 📝 Project Overview

TechWave is a **modern, responsive podcast website** designed to showcase episodes, highlight the host, and provide listeners with easy access to subscribe and listen on multiple platforms. The website features clean UI, smooth navigation, and embedded multimedia for featured content.

Live Demo: [https://sohanur-rahman-coding.github.io/Tech-Wave/](https://sohanur-rahman-coding.github.io/Tech-Wave/)

GitHub Repository: [https://github.com/sohanur-rahman-coding/Tech-Wave](https://github.com/sohanur-rahman-coding/Tech-Wave)

---

## ✨ Key Features

* 📍 **Responsive Navigation Bar** with mobile-friendly hamburger menu
* 🎯 **Interactive Banner Section** highlighting new episodes
* 📊 **About Section** detailing the podcast’s mission and achievements
* 💡 **“Why Choose TechWave” Section** showcasing key benefits
* 📺 **Featured Episodes** with embedded YouTube videos
* 🧑‍🎤 **Meet the Host** section with social profile links
* 📍 **Footer Section** linking to platforms like Spotify, Apple Podcasts, YouTube, etc.

---

## 🛠️ Technology Stack

* **HTML5** for structure
* **CSS3 / Tailwind CSS** for styling
* **Font Awesome** for icons
* **Embedded YouTube Iframes** for featured episodes

---

## 💻 Local Installation

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sohanur-rahman-coding/Tech-Wave.git
   ```
2. Open `index.html` in your browser.

---

## 🚀 Usage

* Navigate through the site using the top navigation links.
* Click on embedded featured episodes to watch directly.
* Use the Subscribe buttons to follow the podcast on platforms like Spotify.
* Connect with the host through the social media links in the **Meet the Host** section.

---

## 🛠 Customization

You can customize the site by modifying:

* The embedded videos in the Featured Episodes section
* Host image and social media icons
* Colors, fonts, and layout in CSS
* Navigation menu and section content
